# Asset provenance

- Interface icons use path data from the installed Iconify Solar icon set by 480 Design. The Solar set is distributed under CC BY 4.0. The source file attributes the icons to 480 Design / Solar.
- Newsreader Variable, Manrope Variable, and Noto Sans SC Variable are installed from Fontsource npm packages and self-hosted in the production bundle. Their font licenses and notices are included with the respective packages in `node_modules`.
- No photographs, portraits, customer logos, endorsements, or externally sourced imagery are used. The cover stack and ticket are authored layout and typography, not representations of personal achievements.
