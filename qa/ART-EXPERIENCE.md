# Interactive sculpture release

2026-11-04. This record supersedes previous hero/navigation descriptions for this release.

## Implemented

- Original parameterised saddle surface inspired by the author's public `breaking bad` observation. The base shape is z=a(x²−y²); local pulling uses a bounded Gaussian displacement. It is explicitly a geometric illustration, not a simulation of the physical experiment.
- Warm surface, blue reverse, direct dragging and elastic release, native curvature input, flat/restore and structure controls. Controls remain available in the reduced-motion/WebGL-failure diagram.
- Static diagram generated by `scripts/generate-surface-poster.mjs` for the no-JavaScript page; its link opens the real archived article.
- Actual experimental photograph and quotation bridge the sculpture to the work. The source is `writing-a04`, 2026-10-19; full photograph/watermark retained.
- Keyboard lazy-loaded near its own section, active only in that section. Chapter resolution uses DOM order. Held keys and pointer capture release on exit. App chapter tracking works before loading and during fallback.
- Two featured Blender films with an expandable complete six-work collection. Original video controls and full article reading remain available.
- Writing precedes a short author note and a smaller contact finale. Star field, general particle backdrop, opening blocker, global elastic-input listeners and game entry removed from this route. Theme, sound, room and editing controls live in the menu.
- Fonts retain their roles. WenKai includes the previous subset and all new Chinese UI characters; see `art-font-subset.json`.

## Checks completed

- TypeScript `tsc --noEmit`: passed.
- Node regression tests: 41 passed, including section reordering, input release, curvature symmetry/bounds, fallback projection, profile migration, complete writing, sync sanitisation and realtime transport.
- Production Vite build: passed with native config loader. Upstream zod annotations are removed by Rollup; no build failure.
- React server-rendered markup: seven chapters in order with unique IDs, range input, explicit model scope, two featured films, static content and same-site assets resolve. See `art-markup-check.json`. This does not execute browser interactions.
- Independent source review found and repaired light-theme hero contrast, cat action focus/fallback, initial chapter state and WebGL fallback obstruction.
