# Motion studies and a more personal type system

The work should move before the interface does. The actual Blender animations become the focal assets; the surrounding controls borrow the clarity of an editing desk. The existing comic keyboard stays the navigation object.

- Palette: retain ink indigo `#19174c`, paper `#e9ece8`, electric blue `#4355df`, warm yellow `#e9c95a`, pink `#d77a92`, and lavender `#a4a7c8` from the current identity.
- Type: Bricolage Grotesque for the name and Latin display; LXGW WenKai for short Chinese titles and personal excerpts; the existing Noto Sans SC for controls and long article text. These are two expressive roles with a neutral reading fallback, replacing the accumulated serif/sans display mix.
- Layout: preserve the spatial keyboard and open artwork composition. Films keep their authored aspect ratios, with a quiet playback strip below; captions are left aligned and short.
- Motion: real source timelines, plus existing GSAP transitions and the sole Lenis scroll engine. No still-image pan is presented as an authored animation. Autoplay is muted and conditional on visibility and motion/data preferences.
- Provenance: original `.blend` files are read only; exported footage records scene, frame range and any presentation-only changes. No invented animation is passed off as source work. Fonts are self-hosted with OFL notices.
- Review: keyboard access, pause/seek, offscreen cleanup, reduced motion, mobile framing, actual differing frames, and production asset loading.

The distinctive element is the user's moving work, not another layer of animated interface decoration. The page should make it easy to see the animation, revisit one moment, and then find the related note or practice.
